INCEPTION - 42 LINUX VM SETUP GUIDE
===================================
Host: Ubuntu 22.04 (42 computer)
Guest: Debian 12 (Bookworm), CLI only
VM: VirtualBox 7.x, 2 CPUs, 4096 MB RAM, 25 GB dynamically allocated disk

IMPORTANT
---------
- Commands in sections 1-2 run on the 42 UBUNTU HOST.
- Commands in sections 4-6 run INSIDE THE DEBIAN VM.
- /var/tmp is potentially temporary and may be cleared. Confirm school policy and back up the VM.
- Never partition the host's physical disk. Select the 25 GB VBOX virtual disk.
- Replace YOUR_USERNAME and YOUR_REPOSITORY_URL where indicated.

1. CHECK THE HOST
-----------------
cat /etc/os-release
VBoxManage --version
lsmod | grep vboxdrv
df -h /var/tmp "$HOME" /goinfre
free -h
ls -lh "$HOME"/Downloads/debian-12*.iso

Make sure the Debian ISO exists and /var/tmp has enough free space.

2. CREATE THE VM (RUN ONCE)
--------------------------
mkdir -p /var/tmp/$USER/inception-vm

VBoxManage createvm --name "Inception" --ostype Debian_64 \
  --basefolder /var/tmp/$USER/inception-vm --register

VBoxManage modifyvm "Inception" --memory 4096 --cpus 2 \
  --nic1 nat --boot1 dvd --boot2 disk --audio-enabled off

VBoxManage createmedium disk \
  --filename /var/tmp/$USER/inception-vm/Inception/inception.vdi \
  --size 25600 --format VDI

VBoxManage storagectl "Inception" --name "SATA" \
  --add sata --controller IntelAhci

VBoxManage storageattach "Inception" --storagectl "SATA" \
  --port 0 --device 0 --type hdd \
  --medium /var/tmp/$USER/inception-vm/Inception/inception.vdi

VBoxManage storageattach "Inception" --storagectl "SATA" \
  --port 1 --device 0 --type dvddrive \
  --medium "$HOME/Downloads/debian-12.12.0-amd64-netinst.iso"

VBoxManage startvm "Inception" --type gui

NOTE: If the VM already exists, do NOT run createvm/createmedium again.
To start an existing VM: VBoxManage startvm "Inception" --type gui

5. INSTALL DOCKER ENGINE + COMPOSE V2 (RECOMMENDED)
-------------------------------------------------
Run as root INSIDE Debian VM.

Remove conflicting packages if present:
apt remove -y docker.io docker-compose docker-doc podman-docker containerd runc

apt update
apt install -y ca-certificates curl
install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/debian/gpg \
  -o /etc/apt/keyrings/docker.asc
chmod a+r /etc/apt/keyrings/docker.asc

cat > /etc/apt/sources.list.d/docker.sources <<'DOCKER_REPO'
Types: deb
URIs: https://download.docker.com/linux/debian
Suites: bookworm
Components: stable
Architectures: amd64
Signed-By: /etc/apt/keyrings/docker.asc
DOCKER_REPO

apt update
apt install -y docker-ce docker-ce-cli containerd.io \
  docker-buildx-plugin docker-compose-plugin

systemctl enable --now docker
docker --version
docker compose version
docker run --rm hello-world

Optional: allow regular user to run Docker without sudo:
usermod -aG docker YOUR_USERNAME
# Log out and log back in to apply group membership.
# WARNING: membership in docker group effectively grants root privileges.

IMPORTANT: 'docker compose' (space) is Compose v2 and matches the Inception Makefile.
'docker-compose' (hyphen) is the older standalone command; do not assume it works
with a Makefile that calls 'docker compose'.

6. CLONE AND START INCEPTION
---------------------------
Log in as regular user after applying permissions.

git clone YOUR_REPOSITORY_URL inception
cd inception
ls -la

Check project-specific environment and secrets first:
ls -la srcs
# Create srcs/.env and required secrets according to YOUR project configuration.
# Do not commit passwords or .env to Git.

docker compose -f srcs/docker-compose.yml ps
docker compose -f srcs/docker-compose.yml logs --tail=80

TROUBLESHOOTING
---------------
Package docker-compose-plugin not found:
  Use the official Docker repository in section 5.
Docker permission denied:
  Use sudo or re-login after joining docker group.
Docker Compose config error:
  Check srcs/.env, secrets, and compose paths before 'make'.
VM booting installer again:
  Remove the Debian ISO from the virtual optical drive.

Official Docker guide: https://docs.docker.com/engine/install/debian/
