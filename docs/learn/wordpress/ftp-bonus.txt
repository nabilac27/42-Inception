You need only four main steps:
1. Dockerfile: Install vsftpd on Debian 12.
2. vsftpd.conf: Configure FTP login, write permissions, and passive ports.
3. init.sh: Create the FTP user, set permissions, and start the server.
4. docker-compose.yml: Add the FTP service and mount your existing wordpress_data volume.

FTP container must have access to the exact same files as your WordPress container, using the same Docker volume.
You don't create a new copy of WordPress. Both containers share one volume.
