### WordPress Slug

A **slug** in WordPress is the URL-friendly name used to identify a post or page.

For example:

| Page Title | Slug | URL |
|---|---|---|
| Home | `home` | `/home/` |
| Posts | `posts` | `/posts/` |
| Posts (duplicate) | `posts-2` | `/posts-2/` |
| Bonus | `bonus` | `/bonus/` |

### How WordPress Uses Slugs

WordPress uses the page's slug to find the corresponding PHP template automatically.

For example, when visiting `/posts/`:

```text
URL: /posts/
      ↓
WordPress finds the page with slug "posts"
      ↓
WordPress looks for page-posts.php
      ↓
Displays the custom Posts page
```

This process is part of the **WordPress Template Hierarchy**.

Why did WordPress create posts-2?
You already had a page with the slug posts.
When you created another page with the same requested slug, WordPress automatically changed it to posts-2 to avoid a duplicate.
Slug vs title
- Title: Human-readable name, such as My First Post.
- Slug: URL-friendly identifier, such as my-first-post.
- Template: PHP file WordPress uses to display the content.
