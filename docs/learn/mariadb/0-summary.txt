# MariaDB

## 1. What is MariaDB?

MariaDB is a relational database management system (RDBMS) used by WordPress to store posts, users, comments, and website settings.

| Concept         | Description                                    |
|-----------------|------------------------------------------------|
| MariaDB         | Relational database management system          |
| SQL             | Language used to manage relational data        |
| `mariadbd`      | Database server process                        |
| `mariadb`       | Command-line database client                   |
| Port `3306`     | Default MariaDB TCP port                       |
| `/var/lib/mysql`| Directory containing database files            |
| `mariadb_data`  | Docker volume for persistent database storage  |

## 2. Server vs Client

| Server (`mariadbd`)              | Client (`mariadb`)                    |
|----------------------------------|---------------------------------------|
| Runs continuously                | Connects to the server                |
| Processes SQL queries            | Sends SQL queries                     |
| Manages database files           | Displays query results                |
| Listens on port 3306             | Connects through TCP or Unix socket   |

**Key concept:** The client sends SQL commands; the server executes them.

## 3. MariaDB Architecture

```text
Browser
   |
   v

   |
   v
WordPress (PHP-FPM) ----+
                        |
Adminer ----------------+----> MariaDB :3306
                                  |

                                  |

```

- WordPress reads and writes website data.
- Adminer provides a database management interface.
- MariaDB processes SQL queries.
- Docker volumes preserve database files.

## 4. MariaDB vs MySQL

| MariaDB                         | MySQL                           |
|---------------------------------|---------------------------------|
| Fork of MySQL                    | Original database system        |
| Community-developed             | Developed by Oracle             |
| Open-source RDBMS               | RDBMS with multiple editions    |
| Used in Inception               | Not required for Inception      |

**Key concept:** MariaDB and MySQL are related database systems, but Inception uses MariaDB.

## 5. Database Configuration

| Setting          | Value               |
|------------------|---------------------|
| Database         | `wordpress`         |
| Database user    | `wp_user`           |
| Service name     | `mariadb`           |
| Port             | `3306`              |
| Data directory   | `/var/lib/mysql`    |
| Persistent volume| `mariadb_data`      |
| Configuration    | `50-server.cnf`     |

### MariaDB Configuration File

```ini
[mysqld]
bind-address = 0.0.0.0
port         = 3306
socket       = /run/mysqld/mysqld.sock
datadir      = /var/lib/mysql
```

| Setting                  | Purpose                              |
|--------------------------|--------------------------------------|
| `[mysqld]`               | MariaDB server configuration section |
| `bind-address = 0.0.0.0` | Listen on all container interfaces   |
| `port = 3306`            | TCP communication port               |
| `socket`                 | Local Unix socket                    |
| `datadir`                | Database storage directory           |

**Why `0.0.0.0`?**

- `127.0.0.1`: Accepts TCP connections only from the same container.
- `0.0.0.0`: Allows connections through the container's network interfaces.

Port 3306 does not need to be published to the host.

## 6. SQL Basics

SQL stands for Structured Query Language.

| Command           | Purpose                         |
|-------------------|---------------------------------|
| `CREATE DATABASE` | Create a database               |
| `CREATE USER`     | Create a database account       |
| `GRANT`           | Assign database permissions     |
| `SELECT`          | Read data                       |
| `INSERT`          | Add data                        |
| `UPDATE`          | Modify data                     |
| `DELETE`          | Delete data                     |
| `SHOW`            | Display database information    |
| `DROP`            | Delete a database or table      |

### Useful SQL Commands

```sql
-- Show databases
SHOW DATABASES;

-- Select WordPress database
USE wordpress;

-- Show tables
SHOW TABLES;

-- Read WordPress posts
SELECT ID, post_title FROM wp_posts;

-- Create database
CREATE DATABASE IF NOT EXISTS wordpress;

-- Create application user (example only)
CREATE USER 'wp_user'@'%' IDENTIFIED BY 'password';

-- Grant permissions
GRANT ALL PRIVILEGES ON wordpress.* TO 'wp_user'@'%';

-- Show database accounts
SELECT User, Host FROM mysql.user;
```

**Key concepts:**

- `wordpress.*` means all tables in the WordPress database.
- `'wp_user'@'%'` means the database account `wp_user` with a wildcard host pattern.
- WordPress should use a dedicated database account instead of root.

## 7. Linux Users vs MariaDB Users vs WordPress Users

| Type           | Example       | Purpose                        |
|----------------|---------------|--------------------------------|
| Linux user     | `mysql`       | Runs the MariaDB server        |
| MariaDB user   | `wp_user`     | Connects to the database       |
| WordPress user | `nchairun`    | Logs in to the website         |

**Key concept:** These are three separate authentication systems.

## 8. Database Initialization Flow

```text
Container starts
       |
       v
Check /var/lib/mysql
       |
       v
Initialize database files if needed
       |
       v
Start temporary MariaDB
       |
       v
Wait until server is ready
       |
       v
Execute SQL commands
       |
       +-- CREATE DATABASE
       +-- CREATE USER
       +-- GRANT
       |
       v
Stop temporary server
       |
       v
exec mariadbd --user=mysql
       |
       v
Final MariaDB server (PID 1)
```

### Why Start MariaDB Twice?

**Temporary server:**

```bash
mariadbd --user=mysql --skip-networking &
```

- Starts in the background.
- Disables TCP networking during initialization.
- Accepts local connections through a Unix socket.
- Allows SQL commands to configure the database.

**Final server:**

```bash
exec mariadbd --user=mysql
```

- Replaces the initialization shell.
- Runs MariaDB as PID 1.
- Handles WordPress and Adminer connections.
- Receives Docker shutdown signals directly.

**Key concept:** The first server configures the database; the second server runs continuously.

## 9. Why Use `exec` and `--user=mysql`?

| Instruction        | Purpose                                      |
|--------------------|----------------------------------------------|
| `exec`             | Replaces the shell process                   |
| `--user=mysql`     | Runs MariaDB with reduced Linux privileges   |
| PID 1              | Main process controlling container lifetime  |
| `--skip-networking`| Disables TCP networking during initialization|

**Key concept:** The final MariaDB server runs as PID 1 under the `mysql` Linux user.

## 10. Docker Networking

```text
WordPress Container
        |
        | TCP :3306
        v
MariaDB Container
        |
        v
Database Files
        |
        v
Docker Volume
```

- Containers communicate using Docker service names.
- WordPress connects to the hostname `mariadb`.
- MariaDB listens on port `3306`.
- MariaDB does not require a publicly exposed port.

## 11. Persistent Storage

MariaDB stores database files in:

```text
/var/lib/mysql
```

Docker Compose volume mapping:

```yaml
volumes:
  - mariadb_data:/var/lib/mysql
```

| Command                | Effect                              |
|------------------------|-------------------------------------|
| `docker compose down`  | Removes containers, keeps volumes   |
| `docker compose up -d` | Recreates containers, reuses data   |
| `docker compose down -v` | Removes Compose-managed volumes   |

**Key concept:** Volumes preserve database data independently of the container's writable layer.

## 12. Docker Secrets

Passwords are provided through Docker secrets.

```bash
DB_PASSWORD=$(cat /run/secrets/db_password)
DB_ROOT_PASSWORD=$(cat /run/secrets/db_root_password)
```

Environment variables provide general configuration:

```dotenv
MARIADB_DATABASE=wordpress
MARIADB_USER=wp_user
```

**Key concept:** Secrets provide passwords; environment variables provide non-sensitive configuration.


## 14. Inception Evaluation Questions

**Q: Why does WordPress need MariaDB?**

To store and retrieve website content, users, comments, and settings.

**Q: What is the difference between `mariadbd` and `mariadb`?**

`mariadbd` is the database server; `mariadb` is the command-line client.

**Q: Why use port 3306?**

It is MariaDB's default TCP port for database connections.

**Q: Why use `bind-address = 0.0.0.0`?**

To accept connections from other containers through the Docker network.

**Q: Why use a Docker volume?**

To preserve database files when containers are removed or recreated.

**Q: Why start MariaDB temporarily?**

To execute SQL commands that initialize the database and user permissions.

**Q: Why use `--skip-networking`?**

To disable TCP connections during temporary initialization.

**Q: Why use `exec`?**

To replace the shell with MariaDB so it becomes PID 1.

**Q: Why run MariaDB as `mysql`?**

To avoid running the database server with Linux root privileges.

**Q: Why use `wp_user` instead of root?**

To limit WordPress access to its own database.

MariaDB runs as a database server inside its own Docker container, accepts WordPress connections over the internal Docker network, and stores persistent data in a Docker volume.
