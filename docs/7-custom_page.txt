WordPress themes use a little PHP.

Here's how it works:
File	        Language	    Purpose
index.php	    HTML + PHP	    Website structure, buttons, links
style.css	    CSS	            Colors, layout, animations
functions.php	PHP         	Loads CSS and other theme resources
script.js (opt)	JavaScript	    Interactive effects and animations

Why index.php instead of index.html?
    Because WordPress uses PHP to generate dynamic content and URLs.

For example, normal HTML:
    <a href="/wp-login.php">Login</a>


WordPress PHP:
    <a href="<?php echo esc_url(wp_login_url()); ?>">Login</a>


Both create a login link, but the PHP version automatically generates the correct WordPress login URL.
