secrets/
    It stores sensitive values, mainly passwords, separately from normal configuration. 
    subject strongly recommends Docker secrets for confidential information.    

---

    .env                         secrets/
    MYSQL_DATABASE=wordpress     db_password.txt
    MYSQL_USER=wpuser            └── actual password
            │                         │
            └────────┐       ┌────────┘
                    ▼       ▼
                docker-compose.yml
                        │
                        ▼
                MariaDB container
                        │
            ┌─────────┴──────────┐
            ▼                    ▼
    MYSQL_DATABASE         /run/secrets/
    MYSQL_USER             db_password

---

The key difference:
    .env      = normal configuration
                "database should be called wordpress"
                "database user should be wpuser"

    secrets/  = confidential information
                "wpuser's password is XXXXX"

---

In docker-compose.yml
    secrets:
    - db_password

        which means:
            Give the MariaDB container access to db_password.

    secrets:
    db_password:
        file: ../secrets/db_password.txt

            means:
            Get that secret from this local file.

Docker then made it available inside the container as:
    /run/secrets/db_password

proves, it worked with:
    docker exec mariadb ls -l /run/secrets/

which showed:
    db_password ✅

One very important rule: 
    secrets/ must be ignored by Git, 
    because subject says passwords/credentials committed to the repository can cause project failure

So the mental model is simply:
    .env = configuration ⚙️ | secrets/ = passwords 🔐.


---

init.sh

DB_PASSWORD=$(cat /run/secrets/db_password)

means
    Docker secret file
    /run/secrets/db_password
            ↓
        cat
            ↓
    shell variable $DB_PASSWORD

---

    $MYSQL_DATABASE  → wordpress   (.env)
    $MYSQL_USER      → wpuser      (.env)
    $DB_PASSWORD     → ********    (Docker secret)

---

mariadbd  = DATABASE SERVER 🗄️
mariadb   = DATABASE CLIENT  💬
