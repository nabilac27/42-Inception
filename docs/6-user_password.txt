WordPress has 6 default user roles, each with different permissions.

+---------------+--------------------------------------------------------------------------+
| Role          | Permissions                                                              |
+---------------+--------------------------------------------------------------------------+
| Administrator | Full control over users, themes, plugins, settings, posts, and comments. |
| Editor        | Can manage posts from all authors and moderate comments.                |
| Author        | Can write, publish, edit, and delete their own posts.                    |
| Contributor   | Can write and edit their own posts but cannot publish them.              |
| Subscriber    | Can log in, manage their profile, and write comments.                    |
| Super Admin   | Manages multiple websites in a WordPress Multisite network.             |
+---------------+--------------------------------------------------------------------------+

Note: Super Admin is only available in WordPress Multisite installations.


secrets/
├── credentials.txt
├── db_password.txt
└── db_root_password.txt


File	                Purpose
db_password.txt	        Password for the MariaDB user that WordPress uses (wp_user)
db_root_password.txt	Password for the MariaDB root administrator
credentials.txt	        Example file for storing or documenting credentials


Prompt	                        File	                Account
[MariaDB] root password:	    db_root_password.txt	root (MariaDB)      Database administration
[MariaDB] user password:	    db_password.txt	        wp_user             WordPress database connection
[WordPress] admin password:	    credentials.txt	        nchairun            Website administration
[WordPress] author password:	credentials.txt	        user                Writing posts


MariaDB root is the database administrator, not the WordPress administrator.


MariaDB wp_user is the database account WordPress uses to connect to MariaDB.

WordPress nchairun is your website administrator.
WordPress user is your website author.


----

During normal operation
WordPress connects using:
    MariaDB user:     wp_user
    MariaDB password: db_password.txt

When would you use MariaDB root?
    For database administration, such as checking databases or managing users:

    docker exec -it mariadb mariadb -u root -p
