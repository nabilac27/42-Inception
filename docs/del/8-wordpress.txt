- WordPress started as a blogging platform, but it grew into a general website-building system.

- Wix, Hostinger, Blogspot?
   - They're related, but not quite the same thing.
   - WordPress is a CMS. You can download WordPress, run it on your own server, connect your own database, modify it, etc.
   - Wix is primarily a hosted website builder/platform. 
      It provides CMS-like content-management features, but you don't normally download Wix and 
      deploy a “Wix container” on your own server.
   - Blogger/Blogspot is Google's hosted blogging platform. 
      It also manages content, but Google operates the infrastructure underneath it.
   - Hostinger is primarily a web-hosting company, not itself a CMS. 
      It can host websites built with WordPress and other tools.

- There isn't really one person who “invented the CMS.” 
- The concept evolved during the 1990s as websites became larger and organizations needed non-programmers to update content.
- One historically important early commercial system was Vignette StoryServer, 
   which grew out of software developed in the mid-1990s for managing web content. 
   Other companies and projects were building similar ideas around the same period.
- WordPress came later, in 2003, created by Matt Mullenweg and Mike Little as a fork/successor of the blogging software b2/cafelog.

---

SQL 
   - stands for Structured Query Language. 
   - It's a language used to communicate with relational databases:
      SELECT * FROM users;
      CREATE DATABASE wordpress;
      DELETE FROM users WHERE id = 5;

MySQL 
   - is a database management system that understands SQL.
      SQL       = language 🗣️
      MySQL     = database software 🗄️
      MariaDB   = database software 🗄️

   - SQL = the language you speak
   - MySQL/MariaDB = the system you're speaking to
