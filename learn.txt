About:
    - build a small website infrastructure using Docker Compose. 

    - It has 3 required containers:
        - NGINX                 = front door, HTTPS only on port 443
        - WordPress + PHP-FPM   = website app
        - MariaDB               = database

    - You must build the images yourself with Dockerfiles, not pull ready-made service images. 
    - Alpine/Debian base images are allowed.

---

Main goal:
    - When I open   https://yourlogin.42.fr

    - I should see a working WordPress website.

    - And behind the scenes:
        Browser
            │ HTTPS (443)
            ▼
        NGINX Container
            │
            ▼
        WordPress + PHP-FPM Container
            │
            ▼
        MariaDB Container

    - Everything runs inside Docker containers connected by a Docker network.

---

    Build your own mini hosting server

    Internet
        ↓
    NGINX (secure entrance)
        ↓
    WordPress (website)
        ↓
    MariaDB (storage)
