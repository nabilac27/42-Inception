# Inception WordPress Theme

A custom `WordPress` theme developed for the 42 Inception project.

The theme uses a minimalist dark design, with custom `HTML` layouts, `CSS` styling, and `PHP` to integrate with `WordPress`.

## Folder Structure

```text
    theme/
    ├── functions.php   # WordPress hooks and login customization
    ├── index.html      # Custom landing page
    ├── index.php       # Page routing and HTML loading
    ├── posts.php       # Posts page layout
    ├── style.css       # Website and login styling
    └── README.md       # Theme documentation
```

## How It Works

```text
  Technology    | Responsibility
  --------------|-----------------------------------------------
  HTML5         | Structures web pages
  CSS3          | Styles and lays out content
  PHP           | Executes server-side logic
  WordPress     | Manages content, users, and templates
  MariaDB       | Stores website data
  Docker        | Runs services in isolated containers
```
**Request flow:** 
```shell
Browser → NGINX → WordPress/PHP → MariaDB → Generated HTML → Browser.
```

`WordPress` manages website content and user accounts, while `MariaDB` stores the associated data.

The `index.php` template can load either `HTML` layout. However, `HTML` alone cannot retrieve published posts from `WordPress`. `Dynamic` post listings must be generated by `PHP` and inserted into the Posts layout.

### WordPress 

<details>
<summary><strong>1. Default Themes</strong></summary>

---

WordPress includes official themes. The installed themes in this Inception project may include:

```text
  Theme                 | Description
  ----------------------|------------------------------------------
  twentytwentyfive      | Official Twenty Twenty-Five theme
  twentytwentyfour      | Official Twenty Twenty-Four theme
```

WordPress core manages content and authentication, while the active theme controls the website's presentation.

<details>
<summary><strong>2. Default Theme Files</strong></summary>

---

For a classic PHP theme, WordPress requires `style.css` and `index.php`.

```text
  File             | Purpose
  -----------------|------------------------------------------
  style.css        | Theme metadata and stylesheet
  index.php        | Required fallback template
  functions.php    | Optional theme functionality
  front-page.php   | Optional front-page template
  single.php       | Optional individual post template
  page.php         | Optional static page template
```
WordPress selects templates through its template hierarchy. If no more-specific template matches, it falls back to `index.php`.

</details>

```text
  Setting                  | Default behavior
  -------------------------|------------------------------------------------
```

<details>
<summary><strong>5. WP-CLI (WordPress Command Line Interface)</strong></summary>

---

WP-CLI is a command-line tool for managing WordPress without using the Admin Dashboard.

**Basic syntax:**

```bash
  wp <command> <subcommand> [options]
```

For example:

```bash
  wp theme list
```

In Inception, run commands inside the WordPress container:

```bash
  docker exec wordpress wp theme list --allow-root
```

- `docker exec` executes a command inside a running container.
- `wordpress` is the container name.
- `wp` invokes WP-CLI.
- `theme list` lists installed themes.
- `--allow-root` permits execution as root.

WP-CLI is useful for inspecting settings, managing themes and content, and troubleshooting your WordPress installation.
</details>

<details>
<summary><strong>6. Useful WP-CLI Commands</strong></summary>

---

WP-CLI (WordPress Command Line Interface) lets you manage WordPress directly from the terminal.

**Theme management**

```bash
  # List installed themes
  docker exec wordpress wp theme list --allow-root

  # Check the active theme
  docker exec wordpress wp option get stylesheet --allow-root

  # Activate the custom theme
  docker exec wordpress wp theme activate inception --allow-root
```

**Website configuration**

```bash
  # Display the site URL
  docker exec wordpress wp option get siteurl --allow-root

  # Display the homepage URL
  docker exec wordpress wp option get home --allow-root

  # Check permalink structure
  docker exec wordpress wp option get permalink_structure --allow-root

  # Check registration settings
  docker exec wordpress wp option get users_can_register --allow-root

  # Check the default user role
  docker exec wordpress wp option get default_role --allow-root
```

**Posts and pages**

```bash
  # List published posts
  docker exec wordpress wp post list \
      --post_type=post \
      --post_status=publish \
      --allow-root

  # List pages and their status
  docker exec wordpress wp post list \
      --post_type=page \
      --fields=ID,post_title,post_name,post_status \
      --allow-root
```

**User management**

```bash
  # List WordPress users
  docker exec wordpress wp user list --allow-root

  # Check a user's role
  docker exec wordpress wp user get nchairun --field=roles --allow-root
```

**Database and troubleshooting**

```bash
  # Check database tables
  docker exec wordpress wp db check --allow-root

  # Display WordPress version
  docker exec wordpress wp core version --allow-root

  # Flush the object cache
  docker exec wordpress wp cache flush --allow-root

  # Regenerate rewrite rules
  docker exec wordpress wp rewrite flush --allow-root
```

**Important notes:**

- WP-CLI must be installed in the container.
- `--allow-root` permits WP-CLI to run as root.

</details>

### Basic Syntax

<details>
<summary><strong>1. HTML5 Boilerplate</strong></summary>

---

The standard structure of an HTML document.

```html
  <!DOCTYPE html>
  <html lang="en">
  <head>
      <meta charset="UTF-8">
      <meta name="viewport" content="width=device-width, initial-scale=1.0">
      <title>Page Title</title>
      <link rel="stylesheet" href="style.css">
  </head>
  <body>
      <header>
          <h1>Website Title</h1>
      </header>

      <nav>
          <a href="/">Home</a>
      </nav>

      <main>
          <h2>Main Content</h2>
          <p>Page content goes here.</p>
      </main>

      <footer>
          <p>Footer content</p>
      </footer>
  </body>
  </html>
```

**Key concepts:**

- `<!DOCTYPE html>` declares an HTML5 document.
- `<head>` contains metadata, the page title, and stylesheet references.
- `<body>` contains the visible page content.
- Semantic elements organize the page.
- `<link>` connects the HTML document to an external stylesheet.

</details>

<details>
<summary><strong>2. CSS3 Boilerplate</strong></summary>

---

The basic structure of a CSS stylesheet.

```css
  * {
      box-sizing: border-box;
  }

  body {
      margin: 0;
      font-family: Arial, sans-serif;
      background: #111111;
      color: #f5f5f5;
  }

  .header {
      display: flex;
      justify-content: space-between;
      align-items: center;
      padding: 20px;
  }

  @media (max-width: 600px) {
      .header {
          flex-direction: column;
      }
  }
```

**Key concepts:**

- Selectors target HTML elements, classes, and IDs.
- Properties define appearance and layout.
- Flexbox aligns and distributes elements.
- Media queries adapt layouts to different screen sizes.
- `box-sizing: border-box` includes padding and borders in declared dimensions.

</details>

<details>
<summary><strong>3. PHP Boilerplate</strong></summary>

---

The basic structure of a PHP script.

```php
  <?php

  $title = "Inception";

  if ($title) {
```

- `htmlspecialchars()` helps safely display untrusted text in HTML.

<details>
<summary><strong>4. WordPress Theme Boilerplate</strong></summary>

---

A minimal WordPress theme requires a `style.css` theme header and an `index.php` template.

**style.css**

  ```css
  /*
  Theme Name: Inception
  Description: Custom theme for the 42 Inception project.
  Author: nchairun
  Version: 1.0
  */

  body {
      margin: 0;
      font-family: "Courier New", Courier, monospace;
  }
  ```

  **index.php**

  ```php
  <?php

  if (is_front_page()) {
      readfile(__DIR__ . '/index.html');
      exit;
  }

  ?>

  <!DOCTYPE html>
  <html lang="en">
  <head>
      <meta charset="UTF-8">
      <meta name="viewport" content="width=device-width, initial-scale=1.0">
      <title><?php bloginfo('name'); ?></title>
      <?php wp_head(); ?>
  </head>
  <body>
      <main>
          <?php if (have_posts()) : ?>
              <?php while (have_posts()) : the_post(); ?>
                  <article>
                      <h1><?php the_title(); ?></h1>
                      <?php the_content(); ?>
                  </article>
              <?php endwhile; ?>
          <?php endif; ?>
      </main>
      <?php wp_footer(); ?>
  </body>
  </html>
```

**Key concepts:**

- `style.css` metadata identifies the theme.
- `index.php` is the required fallback template.
- `is_front_page()` checks whether the current page is the front page.
- `readfile()` outputs the contents of `index.html`.
- `have_posts()` and `the_post()` loop through WordPress content.
- `the_title()` and `the_content()` display content.
- `wp_head()` and `wp_footer()` provide hooks for WordPress and plugins.

</details>

<details>
<summary><strong>5. WordPress Functions Boilerplate</strong></summary>

---

The `functions.php` file registers theme functionality and hooks.

  ```php
  <?php

  function inception_styles()
  {
      wp_enqueue_style(
          'inception-style',
          get_stylesheet_uri()
      );
  }

  add_action('wp_enqueue_scripts', 'inception_styles');

  function inception_login_title()
  {
      return 'INCEPTION';
  }

  add_filter('login_headertext', 'inception_login_title');
  ```

**Key concepts:**

- `functions.php` loads automatically for the active theme.
- `add_action()` registers a function to run at a specific point.
- `add_filter()` modifies a value used or returned by WordPress.
- `wp_enqueue_style()` loads a stylesheet.
- `get_stylesheet_uri()` returns the active theme's stylesheet URL.

</details>

<details>
<summary><strong>6. WordPress Query Boilerplate</strong></summary>

---

A basic example of retrieving published posts dynamically.

  ```php
  <?php

  $posts = new WP_Query(array(
      'post_type'      => 'post',
      'post_status'    => 'publish',
      'posts_per_page' => -1
  ));

  if ($posts->have_posts()) {
      while ($posts->have_posts()) {
          $posts->the_post();

          the_title('<h2>', '</h2>');
          the_excerpt();
      }
  }

  wp_reset_postdata();

  ?>
```

**Key concepts:**

- `WP_Query` retrieves content matching specified criteria.
- `post_type` selects the content type.
- `post_status` filters by publication status.
- `posts_per_page` controls the number of results.
- `the_title()` and `the_excerpt()` display post information.
- `wp_reset_postdata()` restores the global post data.

</details>
